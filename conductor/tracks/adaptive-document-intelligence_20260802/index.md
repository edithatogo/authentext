## Scope summary

Authentext will use one adaptive runtime skill. It profiles the requested
operation, document type, purpose, audience, stakes, authority, lifecycle, and
constraints before choosing focused guidance. Current external guidance is
researched only when material and permitted, using nonsensitive profile
metadata and auditable source receipts.
