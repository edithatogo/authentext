## Scope Summary

The track establishes current Authentext discovery and publication across
portable Agent Skills registries and justified host plugin systems. It covers
GitHub Copilot, Claude, Codex/ChatGPT, Gemini CLI, OpenCode, Cursor, Windsurf,
Cline, AiderDesk, AMP, skills.sh, VoltAgent, and reviewed secondary directories.

The root portable skill remains authoritative. Host packages are generated
distribution products, and every external publication remains an explicit
approval gate with a hosted receipt.
